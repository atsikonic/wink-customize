# Image Layout Features

This document explains the image layout features that have been added to the Wink CMS.

## Features Added

### 1. Fixed Frontend Rendering Issue
- **Problem**: Horizontal image layouts worked in the admin editor but displayed as vertical (image on top, caption below) on frontend pages
- **Solution**: Created a separate `frontend.scss` file with embedded image styles that can be included on public pages

### 2. New Layout Option
- **Added**: "Horizontal (Image Right, Caption Left)" layout option
- **Value**: `horizontal-reverse`
- **Behavior**: Displays image on the right side and caption on the left side

## Available Layout Options

1. **Default (Vertical)** - `default`
   - Image displayed on top
   - Caption displayed below, centered
   - Standard vertical stacking

2. **Wide Image** - `wide`
   - Image displayed at larger width (up to 1024px)
   - Caption displayed below, centered
   - Good for hero images

3. **Horizontal (Image Left, Caption Right)** - `horizontal`
   - Image and caption displayed side by side
   - Image on the left, caption on the right
   - Responsive: stacks vertically on mobile

4. **Horizontal (Image Right, Caption Left)** - `horizontal-reverse`
   - Image and caption displayed side by side
   - Image on the right, caption on the left
   - Responsive: stacks vertically on mobile

## Available Size Options

1. **Default** - `default`
   - Image displays at full width (100%)
   - Standard size for most use cases

2. **Small** - `small`
   - Image constrained to 200px max-width
   - Good for thumbnails or small illustrations

3. **Medium** - `medium`
   - Image constrained to 400px max-width
   - Balanced size for content images

4. **Large** - `large`
   - Image constrained to 600px max-width
   - Good for featured images or important visuals

## Files Modified

### 1. `resources/sass/frontend.scss` (NEW)
- Contains CSS styles for embedded images on frontend pages
- Includes all layout options: default, wide, horizontal, horizontal-reverse
- Responsive design for mobile devices

### 2. `webpack.mix.js`
- Added compilation of `frontend.scss` to `public/frontend.css`
- Frontend CSS file can be included on public pages

### 3. `resources/js/components/editorComponents/ImageUploader.vue`
- Added new layout option: "Horizontal (Image Right, Caption Left)"
- Added new size option dropdown with 4 size choices
- Updated dropdown with all four layout options and four size options

### 4. `resources/js/components/editorComponents/WinkImageBlot.js`
- Added support for `data-size` attribute
- Updated to store and retrieve size information

### 5. `resources/sass/editor.scss`
- Added CSS for `horizontal-reverse` layout
- Added CSS for all size options (default, small, medium, large)
- Added size-specific overrides for horizontal layouts
- Updated responsive styles to include new layout

## How to Use

### For Frontend Pages

1. **Include the frontend CSS** in your public page templates:
   ```html
   <link rel="stylesheet" href="/vendor/wink/frontend.css">
   ```

2. **The HTML structure** is automatically generated by the WinkImageBlot:
   ```html
   <div class="embedded_image" data-layout="horizontal" data-size="medium">
       <div class="image-container">
           <img src="image-url" alt="caption text">
       </div>
       <p class="image-caption">Caption text</p>
   </div>
   ```

### For Admin Interface

The admin interface automatically includes the necessary styles through the existing `light.css` and `dark.css` files.

## Responsive Behavior

All horizontal layouts automatically switch to vertical stacking on screens smaller than 768px:
- Images display at full width
- Captions are centered below the image
- Maintains readability on mobile devices

## Example Usage

See `size-test-example.html` for a complete example of all layout and size options in action.

## Compilation

After making changes, compile the assets:
```bash
npm run dev
```

This will generate:
- `public/frontend.css` - For frontend pages
- `public/light.css` - For admin interface (light theme)
- `public/dark.css` - For admin interface (dark theme)
